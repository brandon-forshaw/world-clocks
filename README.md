# World Clocks

A Firefox extension that turns the new tab page into a globe showing the local
time at the places you work with.

- Working hours per site, with "starting soon" and "leaving soon" warnings
- Public holidays for the UK, Ireland, Ontario, Alberta, Victoria, South Africa,
  Bulgaria and India
- A finder for the next window when everyone is in working hours
- A time converter with copyable text for calendar invites
- A toolbar popup and a settings page; sites sync with Firefox Sync

## Install

Open https://brandon-forshaw.github.io/world-clocks/ in Firefox and click
**Install in Firefox**. It updates itself after that.

The built-in sites are only examples. Set up your own on the settings page
(the Settings link on the new tab, or about:addons > World Clocks > Preferences).
